## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`draw.py` (build time only, Python + Pillow) draws `entry.png` at
1024x1024. `main.ts` (Node 22, standard library only) copies that PNG
to `$MAKEFUN_OUTPUT_DIR/entry.png`, deterministically, with no network.
